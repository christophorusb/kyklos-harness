# Naming the harness

Current name in code: **Kyklos** (κύκλος, "circle, cycle": the agent loop), since 2026-10-24.

History, all on 2026-10-24:
1. **Kensho** → dropped: it conflicts with Kensho Technologies (S&P Global's AI company), which also holds the name on PyPI, npm and GitHub.
2. **Shoshin** → dropped: the user didn't vibe with it.
3. **Kyklos** → current.

Checks were done 2026-10-24: a web search for AI/tech products with the name, plus PyPI, npm and GitHub. This is not a trademark search.

## Marked

- ⭐ **Kyklos** (κύκλος): chosen. No AI product found; PyPI free; npm used by a small React hooks library.
- ~~Shoshin~~ (初心, "beginner's mind"): dropped.
